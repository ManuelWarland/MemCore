# Code of conduct

This is a small project. The rule is short: **be decent.**

- Assume good faith. Critique code and ideas, not people.
- No harassment, slurs, personal attacks, or demeaning comments — in issues,
  pull requests, discussions, commit messages, or anywhere else tied to the
  project.
- Off-topic promotion, spam, and bad-faith argument will be closed without
  ceremony.

The maintainer has the final say on what stays and what goes, and may edit,
lock, or delete contributions and block accounts that don't fit the above.

## Reporting a problem

If someone's behaviour is a problem and you can't or don't want to raise it in
the open, use GitHub's private report:
[Report a vulnerability](https://github.com/AngwattRider/MemCore/security/advisories/new)
(it's the same private channel, misuse of the label is fine here). Include links
and enough context to see what happened. Reports are read; expect a reply within
about a week.
